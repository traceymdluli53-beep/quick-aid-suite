# Quick Aid Suite

Prompt: Build SmartAssist AI

1. Role

Act as an expert web developer and AI integration specialist.

2. Objective

Build SmartAssist AI, an interactive, responsive web application that combines three AI tools into one platform.

3. Context

The application helps students, educators, IT facilitators, and professionals improve productivity, save time, and communicate effectively. Users must access all features immediately without logging in or signing up.

4. Requirements

Dashboard: Create a modern homepage with navigation and cards for all three AI tools.

Smart Email Generator: Generate professional emails using a topic, recipient, key points, and selectable tones. Allow users to edit, copy, and regenerate emails.

Meeting Notes Summarizer: Summarize pasted meeting notes and extract key points, decisions, action items, and deadlines.

AI Chatbot: Answer questions, support follow-up conversations, display chat history, and allow users to clear conversations.

Design: Use a clean, professional interface with responsive layouts, smooth animations, interactive buttons, and optional dark mode.

AI Integration: Connect all three tools to a real AI API. Secure API keys using server-side environment variables.

Functionality: Include loading indicators, error messages, copy buttons, clear buttons, and regenerate options.

Technology: Use React, TypeScript, and Tailwind CSS, or equivalent technologies supported by the website builder.

No Authentication: Do not include login, registration, sign-ups, or authentication pages.

Working Application: Build functional features, not just a visual prototype. Clearly explain any API setup required.

5. Output

Deliver a complete, working, mobile-friendly SmartAssist AI web application with all three AI tools integrated into one dashboard, accessible immediately without signing in.
